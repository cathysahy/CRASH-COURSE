# KIVY CRASH COURSE
=================


Ce projet a été réalisé dans le cadre de mon apprentissage du framework Kivy avec Python.

Pour ce travail, je me suis appuyée sur le tutoriel **Kivy Crash Course**, qui contient 14 vidéos expliquant différentes fonctionnalités de Kivy.

J'ai repris les exemples du tutoriel afin de les tester, de comprendre leur fonctionnement et de pratiquer les notions présentées dans chaque vidéo.

## Objectifs

Le but de ce travail est de me familiariser avec Kivy et d'apprendre à créer des applications avec une interface graphique.

Au cours des exercices, j'ai découvert notamment :

- La création d'une application avec Kivy.
- L'utilisation des widgets et leurs interactions.
- Le langage KV.
- Les propriétés de Kivy.
- Le dessin sur le canevas.
- La correction des erreurs.
- La création des animations.
- L'organisation des interfaces.
- La gestion de plusieurs écrans.
- Quelques fonctionnalités liées à Android.

## Organisation des dossiers

Le projet contient 14 dossiers, chacun correspondant à une vidéo du tutoriel.

1. Création d'une application simple
2. Création d'un APK Android
3. Interactions avancées avec les widgets
4. Découverte du langage Kivy
5. Combinaison de Python et du langage KV
6. Utilisation des propriétés Kivy
7. Dessin sur le canevas Kivy
8. Correction des erreurs
9. Création d'une étiquette défilante
10. Gestion et organisation des dispositions
11. Animation et gestion de l'horloge
12. Utilisation des API Android
13. Création du panneau de paramètres
14. Gestion des écrans avec ScreenManager

Chaque dossier contient les fichiers correspondant à la partie étudiée.

## Environnement utilisé

- Système : Kali Linux
- Langage : Python 3.13
- Framework : Kivy 2.3.1
- Langage d'interface : KV
- Gestion des versions : Git et GitHub

J'utilise un environnement virtuel nommé `kivy_venv` pour travailler avec Kivy sans modifier l'installation Python du système.

## Installation et exécution

### Activer l'environnement virtuel

```bash
source "$HOME/Framwork KIVY/kivy_venv/bin/activate"
```

### Vérifier Python et Kivy

```bash
python --version
python -m pip show kivy
```

### Lancer un exemple

Pour exécuter le premier exercice :

```bash
cd "1.Création d'une application simple"
python main.py
```

Pour les autres exercices, il suffit d'accéder au dossier correspondant et de lancer le fichier Python disponible.
